# Support

Aftertrace is a local Mac app for time, cost and usage of your AI coding tools. It is not a hosted service.

- **Questions** — [GitHub Discussions](https://github.com/RahulKraken/aftertrace/discussions)
- **Bugs and feature requests** — [Issues](https://github.com/RahulKraken/aftertrace/issues), using the templates
- **Something that should have stayed on the machine** — private report via [SECURITY.md](SECURITY.md)

Do not attach real traces, prompts, or filesystem paths. `aftertrace demo` is enough to reproduce most engine bugs.
